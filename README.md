# My Vanilla Node App

A test project for building a Node.js app with no frameworks, made for learning.

## Description

This project shows how to build a Node.js application using only the modules that come with Node (`http`, `fs`, `path`, `url` and others), without Express or other third-party frameworks.

The goal is to learn what frameworks usually hide, such as:

* Creating an HTTP server with the built-in `http` module
* Routing requests by hand
* Serving static files and handling request/response bodies
* Organizing a Node project from scratch

> **Note:** This is a learning project and is not meant for production use.

## Getting Started

### Dependencies

* [Node.js](https://nodejs.org/) (LTS version recommended)
* npm (comes with Node.js)
* Any OS that runs Node.js (Windows, macOS, Linux)

### Installing

1. Clone the repository:
   ```
   git clone https://github.com/kielcadiz/my-vanilla-node-app.git
   ```
2. Go into the project folder:
   ```
   cd my-vanilla-node-app
   ```

No extra packages need to be installed. The project only uses Node's built-in modules.

### Executing program

Run the entry point with Node:
```
node index.js
```

## Help

To check that Node.js and npm are installed, run:
```
node -v
npm -v
```
